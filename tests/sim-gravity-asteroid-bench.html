N-Body Gravitational Simulation — Upper Limit Benchmark

This tool measures server-side compute time for the gravity-asteroid batch handler across different body counts and batch sizes. Run this to determine the safe upper limit for N on the target deployment server before raising the 200-body cap. Two methods are tested: direct O(N^2) pairwise force (reference) and Barnes-Hut quadtree O(N log N) (production). Results are compared to the 16 ms frame budget target (60 fps equivalent per batch step).
